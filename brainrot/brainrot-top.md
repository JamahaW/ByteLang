# ByteLang - Спецификация языка программирования
*Версия 2.0 - на основе актуального видения*

## Хронология развития

### Фаза 1: Прототип (v0.1)
- Линейный байт-код без стека
- Только нативные функции с явными адресами
- Базовые математические операции
- Простой формат .blc файла

### Фаза 2: Структуризация (v0.5)
- Добавлен стек для поддержки локальных переменных
- Введены инструкции `call`/`ret` для вызова функций
- Появились глобальные и локальные переменные
- Базовый контроль потока выполнения

### Фаза 3: Абстракции (v1.0)
- Модульная система с `import`
- Структуры и методы
- Generic типы как функции времени компиляции
- Компилятор с трансформациями в core-инструкции

### Фаза 4: Актуальная версия (v2.0)
- Единообразная система символов (`def` для всего)
- Явное разделение нативных и пользовательских функций
- Поддержка времени компиляции (`load`, generic)
- Полноценная система типов с указателями
- Четкая модель памяти и стека

## Спецификация ByteLang v2.0

### 1. Философия и принципы

ByteLang — компилируемый язык системного уровня для встраиваемых систем и сред с ограниченными ресурсами. Основные принципы:

1. **Прозрачная компиляция** — высокоуровневые конструкции явно преобразуются в примитивные инструкции
2. **Минимальный рантайм** — исполнитель реализует только ядро инструкций
3. **Явное управление памятью** — программист контролирует размещение данных
4. **Статическая типизация** — все типы проверяются во время компиляции
5. **Расширяемость** — новые инструкции добавляются без изменения компилятора

### 2. Базовая архитектура

#### 2.1 Модель исполнения
- **Исполнитель (VM)**: интерпретирует байт-код, реализует нативные инструкции
- **Компилятор**: преобразует ByteLang в байт-код, выполняет трансформации
- **Формат .blc**: заголовок + data-секция + code-секция

#### 2.2 Состояние VM:
```c
struct VM_State {
    uint8_t* memory;      // общая память (data + stack)
    size_t data_size;     // размер data-секции
    size_t stack_size;    // размер стека
    
    uint16_t ip;          // instruction pointer
    uint16_t sp;          // stack pointer
    uint16_t fp;          // frame pointer
    
    bool running;         // флаг выполнения
};
```

### 3. Синтаксис и семантика

#### 3.1 Символы
Все именованные сущности — символы, объявляемые через `def`:
```rust
def имя = значение
pub def имя = значение   // публичный символ
```

#### 3.2 Типы данных
**Примитивные типы:**
- Целые: `i8`, `i16`, `i32`, `i64`, `u8`, `u16`, `u32`, `u64`
- С плавающей точкой: `f32`, `f64`
- Логический: `bool`
- Специальные: `void`, `type`

**Составные типы:**
```rust
def Ptr = *i32           // указатель
def Arr = []u8           // массив (динамический)
def FixedArr = [10]i32   // массив фиксированного размера
```

**Пользовательские типы:**
```rust
// Структура
def Point = struct {
    x: i32,
    y: i32,
}

// Generic тип (функция времени компиляции)
def Vector = fn(T: type) type {
    return struct {
        x: T,
        y: T,
        def Self = Vector(T)
    }
}
```

#### 3.3 Модульность
Модуль — файл `.bl`. Каждый модуль имеет свой реестр символов.
```rust
def math = import "math.bl"   // импорт модуля
def data = load "data.bin"    // загрузка данных (compile-time)
```

### 4. Функции

#### 4.1 Нативные функции
Привязка к инструкциям исполнителя:
```rust
pub def exit = cast(*(code: u32)void, 0x00)
pub def add = cast(*(ret: *i32, a: *i32, b: *i32)void, 0x10)
```

#### 4.2 Пользовательские функции
```rust
pub def calculate = fn(x: i32, y: i32) i32 {
    var result: i32 = input()
    math.add(&result, &result, &x)
    math.add(&result, &result, &y)
    return result
}
```

#### 4.3 Сигнатуры функций
```rust
def UnaryOp = *(ret: *i32)void
def BinaryOp = *(ret: *i32, a: *i32, b: *i32)void
```

### 5. Переменные и память

#### 5.1 Глобальные переменные
Размещаются в data-секции, инициализируются при загрузке:
```rust
var initialized: i32 = 100
var uninitialized: i32 = undefined
var struct_var: Point = { x = 10, y = 20 }
```

#### 5.2 Локальные переменные
Размещаются на стеке функции:
```rust
def example = fn() void {
    var local: i32 = 50
    var temp: i32 = undefined
}
```

#### 5.3 Соглашение о вызовах
1. Параметры передаются через стек
2. Возвращаемое значение передается через неявный параметр-указатель `ret`
3. Кадр стека: `[аргументы][возвращаемое][локальные][адрес_возврата][старый_FP]`

### 6. Структуры и методы

#### 6.1 Определение структуры
```rust
def User = struct {
    // Поля
    pub name: []u8,
    age: i32,
    
    // Статические члены
    var static_count: i32 = 0,
    
    // Методы
    def init(self: *Self, name: []u8) void {
        self.name = name
        self.age = 0
    }
    
    def get_age(self: *Self) i32 {
        return self.age
    }
}
```

#### 6.2 Использование структур
```rust
var user: User = undefined
user.init("Alice")
var age = user.get_age()
```

### 7. Generic система

#### 7.1 Generic типы
```rust
def Container = fn(T: type) type {
    return struct {
        data: *T,
        size: usize,
        
        def Self = Container(T)
        
        def get(self: *Self, index: usize) T {
            return self.data[index]
        }
    }
}
```

#### 7.2 Инстанцирование
```rust
def IntContainer = Container(i32)
def FloatContainer = Container(f32)
```

### 8. Инструкции ядра (Core Instructions)

#### 8.1 Управление выполнением
```
0x00: exit(code: u32)                 // завершение программы
0x01: call(func: *void, stack: u8)    // вызов функции
0x02: ret()                           // возврат из функции
```

#### 8.2 Работа со стеком
```
0x30: push_address(addr: *void)       // поместить адрес на стек
0x31: push_const(value: i32)          // поместить константу на стек
0x32: push_var(source: *i32)          // поместить значение переменной
0x33: pop_in(dest: *i32)              // снять значение со стека
```

#### 8.3 Работа с памятью
```
0x20: store(addr: *i32, value: i32)   // записать константу по адресу
0x21: copy(dst: *i32, src: *i32)      // копировать между адресами
```

### 9. Процесс компиляции

#### 9.1 Фазы компиляции:
1. **Лексический анализ** → токены
2. **Синтаксический анализ** → AST
3. **Разрешение символов** → таблица символов
4. **Проверка типов** → аннотированное AST
5. **Трансформации** → развертывание конструкций
6. **Генерация кода** → байт-код

#### 9.2 Трансформации:

**Функции с возвращаемым значением:**
```rust
// Исходно
def add = fn(a: i32, b: i32) i32 {
    return a + b
}

// После трансформации
def add = fn(ret: *i32, a: i32, b: i32) void {
    var __temp: i32
    math.add(&__temp, &a, &b)
    core.copy(ret, &__temp)
    core.ret()
}
```

**Вызовы функций:**
```rust
// Исходно
var result = add(10, 20)

// После трансформации
var result: i32 = undefined
core.push_const(10)
core.push_const(20)
core.call(add, 8)  // stack_alloc = 8 байт
core.pop_in(&result)
```

#### 9.3 Таблица символов
Каждый символ имеет запись:
```rust
struct Symbol {
    name: String,
    type: SymbolType,  // VAR, FUNC, TYPE, MODULE
    data_type: TypeInfo,
    address: usize,    // адрес в data/code секции
    scope: ScopeInfo,
    is_public: bool,
}
```

### 10. Формат исполняемого файла (.blc)

#### 10.1 Структура файла:
```
Offset  Size   Описание
────────────────────────────────
0x0000  2      Magic: "BL" (0x42 0x4C)
0x0002  1      Версия формата (2)
0x0003  1      Размер указателя (1,2,4,8)
0x0004  2      Размер data-секции
0x0006  2      Размер code-секции
0x0008  2      Точка входа (адрес main)
0x000A  2      Флаги
0x000C  N      Таблица символов (опционально)
0xXXXX  M      Data-секция (глобальные переменные)
0xYYYY  P      Code-секция (байт-код)
```

#### 10.2 Data-секция:
Последовательное размещение всех глобальных переменных. Выравнивание по размеру типа.

#### 10.3 Code-секция:
Последовательность инструкций в формате:
```
[опкод: 1 байт][аргументы...]
```

### 11. Модель исполнения

#### 11.1 Инициализация VM:
1. Загрузка .blc файла
2. Настройка указателей: IP = entry_point, SP = data_size
3. Инициализация глобальных переменных
4. Запуск цикла выполнения

#### 11.2 Цикл выполнения:
```c
while (vm.running) {
    uint8_t opcode = vm.memory[vm.ip];
    vm.ip++;
    
    switch (opcode) {
        case 0x00: vm_exit(); break;
        case 0x01: vm_call(); break;
        case 0x02: vm_ret(); break;
        case 0x20: vm_store(); break;
        // ... другие инструкции
        default: vm_error("Unknown opcode");
    }
}
```

#### 11.3 Стек вызовов:
```
Высокие адреса
    ...
    | локальная N  | ← SP (текущий кадр)
    | локальная 1  |
    | возвращаемое |
    | аргумент M   |
    | ...         |
    | аргумент 1   |
    | адр.возврата | ← FP предыдущего кадра
    | старый FP    |
    ...           |
Низкие адреса
```

### 12. Система типов

#### 12.1 Иерархия типов:
```
Type
├── Primitive (i32, u8, bool, void)
├── Pointer (*T)
├── Array ([]T, [N]T)
├── Function (fn(...) T)
├── Structure (struct { ... })
└── Type (сам тип type)
```

#### 12.2 Проверка типов:
- Присваивание: типы должны совпадать точно
- Указатели: могут быть приведены к `*void` и обратно
- Вызов функций: проверка количества и типов аргументов
- Generic: проверка во время инстанцирования

### 14. Пример полной программы

#### 14.1 Модуль `math.bl`:
```rust
def core = import "core.bl"

def BinOp = *(ret: *i32, a: *i32, b: *i32)void

pub def add = cast(BinOp, 0x10)
pub def sub = cast(BinOp, 0x11)
pub def mul = cast(BinOp, 0x12)
pub def div = cast(BinOp, 0x13)
```

#### 14.2 Модуль `main.bl`:
```rust
def core = import "core.bl"
def math = import "math.bl"

def Vector2 = fn(T: type) type {
    return struct {
        x: T,
        y: T,
        
        def Self = Vector2(T)
        
        def dot(self: *Self, other: Self) T {
            var x_mul: T
            var y_mul: T
            var result: T
            
            math.mul(&x_mul, &self.x, &other.x)
            math.mul(&y_mul, &self.y, &other.y)
            math.add(&result, &x_mul, &y_mul)
            
            return result
        }
    }
}

def Vec2i = Vector2(i32)

var v1: Vec2i = { x = 1, y = 2 }
var v2: Vec2i = { x = 3, y = 4 }
var result: i32 = 0

pub def main = fn() void {
    result = v1.dot(v2)  // 1*3 + 2*4 = 11
    
    // Демонстрация низкоуровневых инструкций
    var temp: i32
    core.push_const(100)
    core.pop_in(&temp)
    
    core.exit(0)
}
```

## Заключение

ByteLang представляет собой баланс между низкоуровневым контролем и высокоуровневыми абстракциями. Язык предназначен для систем, где важны предсказуемость выполнения, минимальные накладные расходы и полный контроль над ресурсами.

Ключевые преимущества:
1. **Прозрачность** — программист всегда понимает, во что компилируется код
2. **Минимализм** — малый размер рантайма и исполняемых файлов
3. **Гибкость** — расширяемая система нативных инструкций
4. **Безопасность** — статическая типизация и проверка во время компиляции

Спецификация является основой для реализации компилятора, исполнителя и инструментария для разработки на ByteLang.
